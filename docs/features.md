# 功能与计算方式总览

本文从使用者视角说明 DoraMonitor 的功能入口和实现链路。具体字段、公式与边界分别在
[用量统计](./tools.md)、[计价](./pricing.md)、[额度估算](./quota-capacity-estimation.md)和
[HTTP API](./api.md) 中展开，不在此重复维护另一份规则。

## 1. 用量页（`/`）

### 工具、设备与时间范围

- 工具页签来自 `src/tools/index.js` 的注册表；某个工具目录不存在或解析失败，不影响其他工具。
- 顶部“今天 / 近 7 天 / 近 30 天 / 全部”控制统计卡、模型列表和最近请求，不会重置图表自己的范围偏好。
- 多设备同步启用后，可按合并、本机或单个对端设备查看。普通页面请求只读本机和对端缓存，不访问共享存储。
- 总 Token = 普通输入 + 模型输出 + 缓存读取 + 缓存创建。缓存命中率 = 缓存读取 ÷
  （普通输入 + 缓存读取 + 缓存创建），没有输入时为 0。请求数来自有效用量记录；事件记录只用于工具次数统计。

### 热力图与每日趋势

- 热力图按本地日历日聚合 Token，可独立选择近 7 天、近 30 天或近 1 年。短范围会重算周列、月份标签和颜色强度。
- 每日趋势独立选择近 7 天或近 30 天，展示连续日期和主要模型曲线；日期没有用量时补零，不把相邻高点误连成“持续消耗”。
- 两套范围数据与顶部统计一次计算、同时返回，切换图表不会重新扫描文件。

### 工作区与模型明细（行存）

- 用量记录同时持久化到本地 SQLite（`~/.doramonitor/doramonitor.db`），支持任意时间范围按工作区、模型切片；
- 「各工作区用量」面板按来源机器（本机 / 对端设备）与贡献工具标注用量，行内可设置仅本机生效的别名；
- 点击每日趋势或热力图的数据点可打开当日明细：小时分布、按模型/工作区分项与逐请求列表；
- 「模型用量明细」按计价身份合并跨工具同名模型，点击行可查看逐请求分页明细；
- 当前视图可导出 CSV。

### 首页额度卡片

- Kimi 与 Codex 卡片显示官方 5 小时和每周窗口的剩余百分比及重置时间。
- 额度页的每张工具／账号卡片都有“首页展示”开关。设置保存在本机 `settings.dashboard.hiddenQuotaCards`，默认全部显示。
- 首页只展示最近一次达到置信度门槛的普通等效额度测算：Kimi 为 95 分，Codex 为 80 分；完整历史留在额度页。

## 2. 额度页（`/quota`）

- 展示额度变化记录、85% / 90% / 95% / 98% 四档缓存命中假设、手动测算和完整历史。
- 默认测算起点是上次测算终点；手动结束会续算上一段，重设起点会先结算可用的上一段。
- 等效金额按区间 API 刊例价费用与额度消耗推算，再按模型结构和指定缓存命中率换算 Token。
- 结果是推测值，不是官方固定额度或真实账单；重置、覆盖率不足和低质量样本会限制或降低结果质量。
- 长程交叉校验已退役，不再展示或定期执行；旧历史与兼容查询字段保留，不删除数据。

详见[额度估算逻辑](./quota-capacity-estimation.md)。

## 3. 价目页（`/prices`）

- 显示内置官方价目、来源币种、缓存命中／写入、输入、输出、上下文与官方来源链接。
- 支持 USD/CNY 展示和汇率设置。内部始终以 CNY 记账，避免反复换算。
- 自定义价格按模型名精确匹配优先，再按最长子串匹配；留空分项继承官方价。
- 在线目录只用于查询和导入价格，失败时回退本地缓存或内置快照，不影响已有价目。

费用公式、峰谷价、长上下文和缓存写入规则见[计价体系](./pricing.md)。

## 4. 多设备同步页（`/sync`）

- 支持本地共享目录、SSH/SCP 和 WebDAV；默认关闭，必须显式启用。
- 可配置设备名、同步周期和连接参数，并可“保存并立即同步”。daemon 每分钟读取最新配置。
- 顶部状态区显示已保存的配置是否完整、最近成功时间、最近失败原因和已知对端设备；“已配置”与“连接已验证”分开表达。
- 每台设备上传自己的日汇总、一分钟额度用量桶和额度样本，再下载其他设备摘要。
- 不同步提示词、代码、会话正文或凭据；工作区目录名随同步通道同步（v4 起，仅用于合并视图展示）；设备名冲突会拒绝覆盖。
- WebDAV 密码只存本机配置，API 只返回 `hasPassword`；表单留空密码表示保留原值。

协议、缓存和 Windows/WSL 示例见[多设备同步](./sync.md)。

## 5. CLI 与后台运行

- `doramonitor`：前台启动 Web 看板。
- `doramonitor web --background --no-open`：跨平台后台启动 Web，先检查 `/api/health`，避免把其他占用端口的程序误认为本服务。
- `doramonitor daemon --background`：跨平台后台启动 daemon 并检查 PID 心跳；`scripts/start-windows.bat` 同时启动 Web 和 daemon。
- `doramonitor status`：输出一行状态；`daemon` 维护状态缓存、额度采样、定期测算和周期同步，Web 仅在 daemon 未运行时回退采样；`sync` 立即同步；`tools` 检查数据目录。
- 源码部署：`npm run deploy` 安装锁定依赖并构建；`--skip-install` 复用依赖，`--start` 或 `--background` 可在构建后启动。

详见[CLI](./cli.md)与[部署](./deployment.md)。

## 6. 本地数据与隐私

- 采集器只读取用量元数据，SQLite 只读，损坏文件隔离处理。
- 默认只监听 `127.0.0.1`，没有账号体系，也不应无保护地暴露到局域网或公网。
- 设置、缓存、额度样本和同步摘要位于 `~/.doramonitor/`；npm 包不包含这些本机数据。

完整边界见[隐私与安全](./privacy.md)，当前限制见[已知限制与注意事项](./limitations.md)。
